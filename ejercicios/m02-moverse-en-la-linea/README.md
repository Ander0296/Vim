# m02 — Moverse dentro de la línea (kata mixta)

## Enunciado

Esta clase tiene errores de tipeo. Dejala idéntica a `objetivo.txt`:

1. Línea 2: `privete` → `private`, y `Strng` → `String`.
2. Línea 3: `unidadez` → `unidades`, y la línea termina en `,` en vez
   de `;`.
3. Línea 6: `Double` (con mayúscula) → `double`.
4. Línea 7: `printn` → `println`.

Kata mixta: no te digo qué comando va en cada cambio. Elegí vos; el par
te dice si había un camino más corto.

Par: 31 teclas (todas, incluido el `:x` y el Enter para salir).

Única regla: sin flechas ni mouse.

## Cómo se corre (desde `~/Proyectos/Vim`)

```
./kata m02
```

Al salir te dice ✅ o ❌ y cuántas teclas usaste contra el par. Con ❌,
corré `./kata m02` otra vez: arranca de cero.

Si te trabás: revisá las Sesiones #15, #17, #18 y #19 de GUIA.md

## Entrega

```
/entrega m02
```
